01 · plan

State manager

Splits the prompt into one gathering task per department. Output schema is a closed set built per request, so an invented department fails validation before any code runs.

gemini-3.5-flash · Vertex AI · Google ADK
02 · gather

Gatherer fleet

One agent per department, fanned out concurrently under a configurable cap. Globs, gates, reads, then assesses each file for relevance.

gemini-3.5-flash · parallel
03 · synthesise

Synthesiser

Compiles one answer in Obsidian-flavoured markdown with inline [[dept/path]] citations back to the files it used.

gemini-3.5-flash
04 · reject

Veto checker

Adversarial. Receives the full source text, not just the citations, and tries to reject: unsupported claims, citations that do not resolve, departments the config never allowed. Vetoes carry revision notes and the answer goes round again.

Claude · structured verdict · operator allowlist
05 · draw

Map

Departments, cited files, and every denied file drawn dashed and locked. One graph builder feeds the live canvas and a self-contained offline page.

The gate non-bypassable · fails closed · in front of the read, not behind the answer
01Path checkDecided on the path. A file you may not read is never opened, so its contents cannot reach a prompt.
02Two configs agreepermissions.yaml AND environment.yaml must both grant it. Disagreement denies.
03Spawn re-checkEvery file a gatherer returns is re-checked centrally against the trusted role.
04ContainmentTraversal, absolute paths, escaping symlinks rejected. Cloud keys checked against the bucket prefix.
05ProvenanceThe path must be a file the department actually holds, so an invented path cannot wear a real department's name.
read(role, dept, path) ⟺ G_perm(role,dept) ∧ G_env(role,dept) ∧ contained(path,dept) ∧ exists(path,dept)
