Most systems quietly drop the files you are not cleared to see. Cartographer draws them, locked, on the map.

An agent fleet that reads across an organization's departments, answers in cited prose, and hands back the map it worked from: every source it used, and every door it found closed.

One prompt, six stations

Station 01 / 06
01

Plan the fan-out

A planner reads the question and decides which departments it touches. Its output schema is a closed set built from the live config, so it cannot name a department that does not exist. Gemini 3.5 Flash · Vertex AI · Google ADK

02

Gate before reading

Every path is checked against the caller's role before a single file is opened. Denials are emitted straight away, which is why the locked nodes reach the map first. gatherers/permissions.py

03

Read in parallel

One gatherer per department, running concurrently. They read whole files rather than guessing from filenames, which is how budget_2026_final.csv gets found from a question about Q3 spend. Gemini 3.5 Flash · Vertex AI

04

Synthesise with citations

The gathered material becomes an answer that cites each specific claim inline, and says plainly when the material it needed was withheld. state_manager/manager_synthesizer.py

05

Try to reject it

An adversarial checker receives the answer, the config and the full source text, then hunts for the reason it is wrong. A veto comes with revision notes concrete enough to act on, and the answer goes round again. Claude · veto/checker.py

06

Draw the map

The approved answer, its sources and the denials become a force-directed graph, rendered live in the app and written out as a self-contained page that works offline. client/viz.py

LEGEND src/agentic/client/viz.py

Every map needs a key

Four kinds of node. The fourth is the one that matters, and the reason the project is called what it is.

answer

The answer

The compiled response, at the centre of the map. Everything it cites hangs off it, so the shape of the graph is the shape of the evidence.

department

A department

One cluster hub per department the planner routed to. Engineering, finance, whatever the config declares — never a name a model invented, because the planner's output schema is a closed set built per request.

file

A file it used

A source the answer actually cited, coloured by its department. Click one in the app and it tells you, in the gatherer's own words, what in it was relevant.

denied

A file it was refused

Drawn dashed and locked rather than omitted. A map that hides its edges is a map you cannot trust, so the shape of what you were not allowed to see is part of the answer.

answer 01 / 04

Fortified means the model never sees it

Filtering a model's output after the fact is not access control. By then the content has already been sent to a provider. Two requests enter the gate below. Only one comes out.

Requested by alice · analyst 2 paths
01

Path check, before opening

Permission is decided on the path. A file you may not read is never opened, so its contents cannot reach a prompt.

02

Two configs must agree

The permissions config and the environment config both have to grant it. Any disagreement denies, and malformed config fails closed.

03

Spawn gate re-check

Every file a gatherer returns is checked again centrally. The check inside the gatherer is an efficiency layer, not the boundary.

04

Containment

Traversal, absolute paths and symlinks that escape a department root are rejected, for a cloud object exactly as for a local file.

05

Provenance

Containment asks whether a path stays inside the department. This asks whether it is a file the department actually holds, so an invented path cannot arrive wearing a real department's name.

ADVERSARY src/agentic/veto/checker.py

Something has to argue against the answer

Every other component is optimising to produce an answer. The veto checker is the only one optimising to catch one that should not ship, and it is told to read looking for the reason the answer is wrong rather than for confirmation that it is right. This is a real rejection, from the first run where the loop fired.

revision 0 · draft awaiting check

Engineering spent $41,200 against a budget of $50,000 [[finance/infra-spend-q3.md]], leaving the quarter under budget by $8,800.

Grounded

It gets the sources, not just the citations

The full text of every cited file travels with the answer, so a claim is checked against the file rather than against the fact that a link was attached to it.

Actionable

A veto comes with instructions

Rejection is not a score. It is revision notes specific enough for the synthesiser to act on, and the answer goes round again, up to a configurable budget.

Honest

It fails closed, and it says so

If the checker refuses, truncates or cannot be parsed, that counts as a veto. An answer that exhausts its retries still ships, carrying a visible unapproved banner, never a silent one.

COVERAGE src/agentic/citations.py

Approved is a verdict, not a measurement

The veto checker returns pass or fail, which is the right output for a gate and a poor one for a reader: it tells you an answer survived without telling you what surviving was close to. These three are computed from the same evidence with no model call, and they scroll up as you read them.

Integritycitations that resolve 0%

Of the wikilink citations in the prose, how many name a file that was really gathered. Treated as pass or fail rather than a gradient: one unresolved citation is a defect, not a slightly lower score.

Groundingparagraphs that cite 0%

Catches the answer that opens with three paragraphs of confident synthesis and cites a file only at the end.

Usagegathered files used 0%

Gatherers over-gather by design, so this is context rather than a target. A low number beside a short answer means material went unused.

caught live, first run

A synthesiser cited [[finance/infra-spend-q3.md]] when the file was [[engineering/infra-spend-q3.md]]. Rendered as markdown the two are indistinguishable — same filename, same confident link — which is precisely why an unresolved citation is named rather than averaged into a percentage. The veto checker rejected the answer; revision 1 was approved with every figure verified.
