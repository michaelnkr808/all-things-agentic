Most systems quietly drop the files you are not cleared to see. Cartographer draws them, locked, on the map.

An agent fleet that reads across an organization's departments, answers in cited prose, and hands back the map it worked from: every source it used, and every door it found closed.

One prompt, six stations

Station 01 / 06
01

Plan the fan-out

A planner reads the question and decides which departments it touches. Its output schema is a closed set built from the live config, so it cannot name a department that does not exist. Gemini Flash · Google ADK

02

Gate before reading

Every path is checked against the caller's role before a single file is opened. Denials are emitted straight away, which is why the locked nodes reach the map first. gatherers/permissions.py

03

Read in parallel

One gatherer per department, running concurrently. They read whole files rather than guessing from filenames, which is how budget_2026_final.csv gets found from a question about Q3 spend. Gemini Flash

04

Synthesise with citations

The gathered material becomes an answer that cites each specific claim inline, and says plainly when the material it needed was withheld. state_manager/manager_synthesizer.py

05

Try to reject it

An adversarial checker receives the answer, the config and the full source text, then hunts for the reason it is wrong. A veto comes with revision notes concrete enough to act on, and the answer goes round again. Claude · veto/checker.py

06

Draw the map

The approved answer, its sources and the denials become a force-directed graph, rendered live in the app and written out as a self-contained page that works offline. client/viz.py

Every map needs a key

The graph has four kinds of node. The fourth is the one that matters, and the reason the project is called what it is.

Answeranswer
The compiled response, at the centre. Everything it cites hangs off it.
Departmentdepartment
One cluster hub per department the planner routed to: engineering, finance, legal, whatever the config declares.
Filefile
A source the answer actually used, coloured by department. Click one and it tells you, in the gatherer's own words, what in it was relevant.
Denieddenied
A file the permission gate refused. It is drawn, dashed and locked, rather than omitted, so the shape of what you cannot see is part of the answer.

Fortified means the model never sees it

Filtering a model's output after the fact is not access control. By then the content has already been sent to a provider. Two requests enter the gate below. Only one comes out.

Requested by alice · analyst 2 paths
01

Path check, before opening

Permission is decided on the path. A file you may not read is never opened, so its contents cannot reach a prompt.

02

Two configs must agree

The permissions config and the environment config both have to grant it. Any disagreement denies, and malformed config fails closed.

03

Spawn gate re-check

Every file a gatherer returns is checked again centrally. The check inside the gatherer is an efficiency layer, not the boundary.

04

Containment

Traversal, absolute paths and symlinks that escape a department root are rejected, for a cloud object exactly as for a local file.

ADVERSARY src/agentic/veto/checker.py

Something has to argue against the answer

Every other component in the pipeline is optimising to produce an answer. The veto checker is the only one optimising to catch one that should not ship, and it is told to read looking for the reason the answer is wrong rather than for confirmation that it is right.

Grounded

It gets the sources, not just the citations

The full text of every cited file travels with the answer, so a claim is checked against the file rather than against the fact that a link was attached to it.

Actionable

A veto comes with instructions

Rejection is not a score. It is revision notes specific enough for the synthesiser to act on, and the answer goes round again, up to a configurable budget.

Honest

It fails closed, and it says so

If the checker refuses, truncates or cannot be parsed, that counts as a veto. An answer that exhausts its retries still ships, carrying a visible unapproved banner, never a silent one.
