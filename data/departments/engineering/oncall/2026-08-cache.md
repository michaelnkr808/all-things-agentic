# Postmortem — Cache Stampede, 2026-08-02

**Duration:** 41m
**Impact:** p99 latency rose from 180ms to 4.2s on the search endpoint.

## Cause
Every cache entry for the search index shared a single TTL, so all keys
expired within the same second and every request fell through to the
database at once.

## Resolution
Added +/- 10% jitter to cache TTLs.
